# 特別捜査本部 — 湾岸線連続傷害事件

## 概要

架空都市・東都湾岸市を舞台にした、レトロSF調の捜査アドベンチャーです。事件、組織「星環会」、物質「ルーメンX」、都市・路線、人物、資料、会話、捜査経緯はすべて創作で、実在の事件・団体・物質・人物・施設とは関係ありません。

## 起動方法

[`index.html`](./index.html) をブラウザで開くと遊べます。HTML単体で動作し、外部ライブラリや画像ファイルは不要です。

## ゲームの目的

12回の行動以内に事件資料4点（複数路線の発生記録、鑑定報告、施設捜索資料、先行事件の捜査資料）を集め、取調べで矛盾を立証して架空の関係者から供述を得ます。

質問、資料調査、証拠提示、問い詰めはいずれも1ターンを消費します。正しい証拠を提示すると動揺ゲージが上がり、動揺100で問い詰めると供述を得られます。誤った証拠提示や早すぎる追及で反発ゲージが100になると、その人物は黙秘します。

## 操作

1. 「証拠資料室」で未調査の資料を確認する。
2. 「取調室」で人物と質問を選ぶ。
3. 証言が出たら、適切な資料を提示して矛盾を立証する。
4. 動揺が100になったら「問い詰める」を選ぶ。
5. 12ターン以内に主要資料4点と供述をそろえる。

本作は完全なフィクションです。
